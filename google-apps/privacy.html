Outlook Calendar Sync: Privacy Policy

Published: Wed 23 September 2026
By morganp

In Programming.

Effective date: 23 September 2026

This policy covers Outlook Calendar Sync, a private, single-user tool run by the owner of this site.

Data accessed

The tool accesses only the site owner's own Google Calendar, with read-only access (scope calendar.readonly). It does not access any other person's data, and it cannot create, change or delete calendar events.

How data is used

Calendar data is used solely to generate the owner's private daily briefing on the owner's own server.

Sharing

Calendar data is not sold, shared or transferred to third parties. It is not used for advertising, and it is not used to train AI or machine learning models.

Storage and revocation

OAuth tokens are stored locally on the owner's server. Access can be revoked at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy

Outlook Calendar Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

This policy may be updated. The effective date above shows the current version.

Contact

Use the support email shown on the Google consent screen.
