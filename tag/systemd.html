Mirroring a remote herdr server

Published: Sat 19 September 2026
By morganp

In Unix & Tools.

tags: herdr ssh systemd homelab terminal dotfiles

The herdr-mirror plugin turns workspaces on a remote herdr server into real local workspaces with live panes, so one window shows every agent on every machine. This post separates the local requirements from the remote ones, sets up key-based access and a systemd user unit, and explains how the connection starts.
