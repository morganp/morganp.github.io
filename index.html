herdr, a terminal for coding agents

Published: Wed 23 September 2026
By morganp

In Unix & Tools.

tags: herdr terminal tmux agents workflow

herdr is a terminal multiplexer built around coding agents. It marks every pane working, blocked or idle, so a stopped agent announces itself, it restores the layout after a restart, and the mouse and the scroll wheel work before you configure anything. This post introduces the tool and compares it with tmux.
