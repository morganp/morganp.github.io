Outlook Calendar Sync is a private, single-user tool run by the owner of this site. It reads the owner's own Google Calendar with read-only access (scope `calendar.readonly`) so that calendar events can be included in a personal daily briefing.

The tool is not offered to the public. No one other than the site owner can sign in to it or use it.
